﻿# Skills for Agents

> A visual-first workflow library for AI coding agents.
> Built to feel more like a product system than a plain Markdown repo.

![Skills for Agents logo](./skillsforagent.png)

## Design Language

- **High contrast.** Clear hierarchy, bold headings, compact copy.
- **Card-driven.** Each skill reads like a product card with a purpose, workflow, and proof.
- **Catalog-first.** The repo now emphasizes browseability, not just raw documentation.
- **Local-first.** The logo image stays in the repo as `skillsforagent.png`.

## At a Glance

| Layer | What it means |
|---|---|
| Identity | `Skills for Agents` is the brand used throughout the repo |
| Layout | The README acts like a landing page with a hero and quick links |
| Skill docs | Every skill uses a consistent callout + workflow layout |
| Catalog | `skills/README.md` is the full directory-style index |

## What’s Inside

- **23 original skills** covering define, plan, build, verify, review, and ship
- **40 new skills** extending the library into product, design, content, data, and agent operations
- **63 total skills** in one cohesive catalog

## How to Use the Catalog

1. Open `skills/README.md` to browse the entire collection.
2. Pick the skill that matches the current phase.
3. Follow the workflow from top to bottom.
4. Verify with the checklist at the end.

## Why This Layout

This repo is now organized like a product catalog:

- **The README is the storefront.**
- **`skills/README.md` is the shelf map.**
- **Each `SKILL.md` is a focused instruction card.**

That keeps the repo easier to scan, easier to expand, and easier for agents to follow.
